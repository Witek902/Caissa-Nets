# Caissa-Nets
Repository with neural nets for Caissa chess engine

## Training data
The training data was generated by Caissa (self-play and data generation), with one exception: the `Fishtest1` dataset, which comes from Stockfish LTC games played on Fishtest (around 1% of total dataset).
